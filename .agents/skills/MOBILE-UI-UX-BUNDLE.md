# Mobile UI/UX skill bundle

Project-local skills for Expo React Native UI work:

| Skill | Purpose | Source |
|---|---|---|
| `mobile-ui-ux` | NOVYX-specific entry point, architecture, accessibility, performance, and verification rules | Project-authored |
| `ui-ux-pro-max` | Searchable UI/UX design database with React Native guidance | Copied with bundled data/scripts |
| `karpathy-guidelines` | Small, scoped, verifiable implementation discipline | Copied |
| `diagnosing-bugs` | Root-cause workflow for broken or slow UI behavior | Copied |
| `tdd` | Regression and test-first workflow | Copied |

The repository already includes Taste Skill for visual direction and GSD Core for workflow control; they were not duplicated.

Start mobile interface tasks with `mobile-ui-ux`. Add only the supporting skill required by the task.

## Antigravity harness

- Root `GEMINI.md` is Antigravity's automatically loaded project harness.
- `.agents/memory/ANTIGRAVITY_UI_UX_MEMORY.md` is its dedicated durable FE UI/UX memory.
- Project-local skills remain under the canonical `.agents/skills/` discovery path.
