# Safe Repository Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove proven-dead tracked files, one unused mobile dependency, and ignored generated artifacts without moving directories or changing product behavior.

**Architecture:** Keep all current application and package boundaries unchanged. The cleanup is split into tracked-file deletion, dependency metadata cleanup, and local artifact cleanup so each part can be reviewed and verified independently.

**Tech Stack:** npm workspaces, Expo SDK 57, React Native 0.86, TypeScript, ESLint, Prettier, Metro/Expo Android export

**Spec:** `docs/superpowers/specs/2026-10-15-safe-repository-cleanup-design.md`

## Global Constraints

- Do not move or rename application, package, test, script, workflow, design, or documentation directories.
- Do not change product behavior, API contracts, UI behavior, native source, environment files, or architecture contracts.
- Do not remove root Expo, React, or React Native dependencies.
- Do not remove `react-native-maps`; `StaffProofFlow.tsx` dynamically imports it and `apps/mobile/app.config.js` configures it.
- Preserve all inherited working-tree changes.
- Do not reset, restore, commit, push, install a new dependency, or run lifecycle scripts.
- Keep the final tracked diff limited to approved deletions, `apps/mobile/package.json`, `package-lock.json`, this plan, and its approved spec.

## Review Focus

- A hidden directory-level component import must block deletion of `apps/mobile/src/components/index.ts`; Task 1 repeats repository-wide caller searches before and after deletion.
- Generated Python bytecode may exist in multiple tracked paths; Task 1 checks `git ls-files`, not only the known directory.
- `react-native-curved-bottom-bar` may be referenced dynamically or in native configuration; Task 2 searches source, configuration, scripts, tests, and documentation before removal.
- npm may rewrite unrelated lock entries; Task 2 requires a focused lockfile diff and rejects unrelated churn.
- Local cleanup must not delete `.env`, native source, or tracked evidence; Task 3 uses an explicit allowlist and checks Git status immediately afterward.

### Task 1: Remove dead tracked export and generated bytecode

**Files:**
- Delete: `apps/mobile/src/components/index.ts`
- Delete: tracked files matching `.agents/skills/ui-ux-pro-max/**/__pycache__/*.pyc`

**Interfaces:**
- Consumes: Existing direct component imports under `apps/mobile/src/**`.
- Produces: No runtime interface; removes an unused barrel surface and generated bytecode only.

- [ ] **Step 1: Confirm the component barrel still has no caller**

Run:

```bash
rg -n "components/index|from ['\"][^'\"]*/components['\"]|from ['\"]\.\.?/components['\"]|require\(['\"][^'\"]*/components['\"]\)" \
  apps packages tests scripts
```

Expected: no matches. Any match is a blocker; update the plan rather than deleting the barrel.

- [ ] **Step 2: List all tracked generated Python bytecode**

Run:

```bash
git ls-files | rg '(^|/)__pycache__/|\.py[co]$'
```

Expected: only generated bytecode/cache paths, currently under `.agents/skills/ui-ux-pro-max/`.

- [ ] **Step 3: Delete the dead tracked files**

Run:

```bash
rm -f apps/mobile/src/components/index.ts
git ls-files | rg '(^|/)__pycache__/|\.py[co]$' | while IFS= read -r file; do
  rm -f -- "$file"
done
```

Expected: the barrel and tracked bytecode are absent; no source `.py` file is removed.

- [ ] **Step 4: Verify the deletion set**

Run:

```bash
git status --short
find . -type f \( -path '*/__pycache__/*' -o -name '*.pyc' -o -name '*.pyo' \) \
  -not -path './node_modules/*' -not -path './.git/*' -not -path './.pi/*'
git ls-files --deleted | rg '(^|/)__pycache__/|\.py[co]$'
```

Expected: deleted entries contain only `apps/mobile/src/components/index.ts` and generated Python bytecode; `find` prints nothing; the final command lists every formerly tracked bytecode file as scheduled for deletion.

- [ ] **Step 5: Verify the mobile compile boundary**

Run:

```bash
npm run typecheck --workspace @novyx/mobile
```

Expected: exit code 0.

### Task 2: Remove the unused mobile dependency

**Files:**
- Modify: `apps/mobile/package.json`
- Modify: `package-lock.json`

**Interfaces:**
- Consumes: `apps/mobile/src/components/NotchedBottomNav.tsx` as the active navigation implementation.
- Produces: Mobile dependency graph without `react-native-curved-bottom-bar`; no source interface changes.

- [ ] **Step 1: Reconfirm there is no dependency caller or native configuration**

Run:

```bash
rg -n "react-native-curved-bottom-bar|CurvedBottomBar" \
  apps packages scripts tests package.json package-lock.json app.config.js eslint.config.mjs vitest.config.ts
```

Expected: matches only in `apps/mobile/package.json` and `package-lock.json`. Historical documentation is not a runtime caller and is intentionally outside this check. Any source, plugin, script, test, or configuration match is a blocker.

- [ ] **Step 2: Remove the dependency and update only package metadata**

Run:

```bash
npm uninstall react-native-curved-bottom-bar \
  --workspace @novyx/mobile \
  --package-lock-only \
  --ignore-scripts
```

Expected: command succeeds without running package lifecycle scripts; the dependency disappears from the mobile manifest and lockfile.

- [ ] **Step 3: Reject unrelated lockfile churn**

Run:

```bash
git diff -- apps/mobile/package.json package-lock.json
```

Expected: the diff removes the mobile dependency declaration and the package's unreachable lock entry only. If npm changes unrelated versions, integrity values, or packages, stop and reduce the lockfile change before continuing.

- [ ] **Step 4: Verify dependency absence and package metadata consistency**

Run:

```bash
rg -n "react-native-curved-bottom-bar|CurvedBottomBar" apps package.json package-lock.json scripts tests || true
node -e "const mobile=require('./apps/mobile/package.json'); const lock=require('./package-lock.json'); if (mobile.dependencies?.['react-native-curved-bottom-bar'] || lock.packages?.['apps/mobile']?.dependencies?.['react-native-curved-bottom-bar'] || lock.packages?.['node_modules/react-native-curved-bottom-bar']) process.exit(1)"
```

Expected: repository search prints nothing; the Node assertion exits with code 0, proving both manifest and lockfile entries are absent. A stale physical folder in `node_modules` is outside this lockfile-only cleanup and must not be treated as a manifest dependency.

- [ ] **Step 5: Verify mobile and workspace type boundaries**

Run:

```bash
npm run typecheck
```

Expected: all workspace typechecks exit successfully.

### Task 3: Remove ignored local artifacts and run final gates

**Files:**
- Delete locally, when present: `.expo/`, `.tmp/`, `tmp/`, `dist/`, `apps/admin-web/dist/`, `apps/admin-web/node_modules/`, `apps/api/dist/`, `apps/mobile/.expo/`, `apps/mobile/android/.gradle/`, `apps/mobile/android/app/build/`, `apps/mobile/android/app/.cxx/`, `scripts/__pycache__/`, `field-dev.log`, `tmp-api-check.log`
- Modify only through generated verification output: none tracked

**Interfaces:**
- Consumes: The explicit cleanup allowlist above.
- Produces: A clean local workspace; build tools recreate required outputs on demand.

- [ ] **Step 1: Prove every cleanup target is ignored or untracked**

Run:

```bash
for path in \
  .expo .tmp tmp dist \
  apps/admin-web/dist apps/admin-web/node_modules apps/api/dist apps/mobile/.expo \
  apps/mobile/android/.gradle apps/mobile/android/app/build apps/mobile/android/app/.cxx \
  scripts/__pycache__ field-dev.log tmp-api-check.log; do
  if [ -e "$path" ]; then
    git check-ignore -q "$path" || { echo "BLOCKED: $path is not ignored"; exit 1; }
  fi
done
```

Expected: exit code 0. Never broaden this list with wildcards at repository root.

- [ ] **Step 2: Delete only the approved local artifacts**

Run:

```bash
rm -rf \
  .expo .tmp tmp dist \
  apps/admin-web/dist apps/admin-web/node_modules apps/api/dist apps/mobile/.expo \
  apps/mobile/android/.gradle apps/mobile/android/app/build apps/mobile/android/app/.cxx \
  scripts/__pycache__
rm -f field-dev.log tmp-api-check.log
```

Expected: listed paths are absent. `.env`, `apps/mobile/android/`, source trees, docs, tests, and tracked evidence remain.

- [ ] **Step 3: Check that local cleanup created no unexpected Git change**

Run:

```bash
git status --short
git diff --name-status
```

Expected: only the approved tracked cleanup, dependency metadata, spec, and plan appear.

- [ ] **Step 4: Run formatting, lint, and type verification**

Run:

```bash

npm run typecheck
```

Expected: all commands exit with code 0.

- [ ] **Step 5: Rebuild the Android export from the cleaned workspace**

- [ ] **Step 6: Remove the verification export and perform final searches**

Run:

```bash
rm -rf dist
rg -n "react-native-curved-bottom-bar|CurvedBottomBar" apps package.json package-lock.json scripts tests || true
rg -n "components/index|from ['\"][^'\"]*/components['\"]|from ['\"]\.\.?/components['\"]" apps packages tests scripts || true
find . -type f \( -path '*/__pycache__/*' -o -name '*.pyc' -o -name '*.pyo' \) \
  -not -path './node_modules/*' -not -path './.git/*' -not -path './.pi/*'
git ls-files --deleted | rg '(^|/)__pycache__/|\.py[co]$'
git diff --check

git diff --stat
git diff
```

Expected:

- the component and dependency searches print nothing;
- the bytecode `find` prints nothing and the deleted-file search lists the formerly tracked bytecode paths;
- `git diff --check` exits with code 0;
- final status and diff contain only approved tracked changes;
- no commit or push is performed.
