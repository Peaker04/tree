Ba workspace tách biệt theo trách nhiệm. Mobile phục vụ Staff và Manager với điều hướng năm hành động đã khóa; Platform Admin dùng dedicated web console.

2. Handoff thông tin

SERVER-AUTHORITATIVE
Manager → StaffTask canonical, tree identity, deadline, checklist snapshot và hướng dẫn.
Staff → SystemField verification, evidence intent và idempotency metadata qua durable outbox.
System → ManagerCanonical task trong WAITING_REVIEW cùng evidence history.
Manager → StaffApproval hoặc rework target/reason; không ghi đè lịch sử hợp lệ.
Ranh giới: ẩn một menu không phải authorization. API vẫn phải kiểm tra role, scope, state và preconditions. Admin không được điều hướng vào task operation; Manager không tự cấp quyền Admin.
