Bản đồ Phụ thuộc Gói và Ranh giới Monorepo

Chiều phụ thuộc đi từ ứng dụng vào public API của packages. Shared packages không nhập ngược mã ứng dụng; bounded context là module logic bên trong apps/api, không phải npm package hoặc microservice.

NO DIRECT PRODUCT-WORK EDITS
FORBIDDEN: PACKAGES → APPS

Không package nào được nhập mã từ apps/mobile, apps/api hoặc ứng dụng tương lai. Chiều phụ thuộc phải giữ một chiều.

FORBIDDEN: CROSS-MODULE SQL + API → UI

API không nhập UI tokens. Module A không trực tiếp mutate dữ liệu do Module B sở hữu; dùng application/module interface.

MONOREPO DEPENDENCY INVARIANTS1. Apps chỉ dùng public API của packages.2. Packages độc lập với app runtime.3. apps/api là modular monolith với 5 logical contexts.4. apps/api đã triển khai; apps/admin-web chưa có mã nguồn.
